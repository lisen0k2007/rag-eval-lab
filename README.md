# RAG-Eval-Lab: Умный поиск по PDF с оценкой качества

Проект представляет собой полноценный RAG-сервис (Retrieval-Augmented Generation) для поиска ответов по PDF-документам. 

Главная особенность: в проекте реализована **инженерия оценки**. Я не просто «написал код и надеюсь, что он работает», а измерил качество поиска (Hit Rate) на собственном датасете и оптимизировал параметры системы.

## 📊 Результаты экспериментов (Evaluation)

В ходе исследования сравнивались разные стратегии нарезки текста (Chunking). Базовый поиск по ключевым словам давал Hit Rate@3 = **42.9%**.

## 🛠 Стек технологий
* **Backend:** Python, FastAPI, Pydantic, Uvicorn
* **LLM:** YandexGPT (через REST API)
* **Векторный поиск:** ChromaDB, Sentence-Transformers
* **Frontend:** Streamlit
* **Инфраструктура:** Docker, Docker Compose
